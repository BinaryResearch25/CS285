## 🧠 What is CS285?

**CS285 — Deep Reinforcement Learning** 是 UC Berkeley 的经典强化学习课程。

课程内容涵盖：

`Imitation Learning`
→ `Policy Gradient`
→ `Actor-Critic`
→ `Q-Learning`
→ `Model-Based RL`
→ `Offline RL`
→ `LLM / RL`
→ `Robotics`

最终目标是理解：

> **How can an agent learn to make intelligent decisions through interaction?**
